# OPC 财税法工作台 — 核心页面交互原型完整规划

## 设计原则

> **极简操作 · 合规为先 · AI 驱动**

- 零学习成本：核心页面不超过 5 个
- 一人多岗适配：快速触达关键信息
- 本地化优先：适配各地 OPC 政策

---

## 页面总览

```
┌─────────────────────────────────────────────────────────────┐
│  ① 首页仪表盘        核心经营数据 + 待办 + 风险 + AI 入口   │
│  ② 财税管理页        记账 + 税务 + 发票（三合一）           │
│  ③ 法务管理页        合同 + 合规 + 法律咨询（三合一）       │
│  ④ 数据中心          经营健康度 + 风险雷达 + 预测 + 导出    │
│  ⑤ 设置与合规中心    公司信息 + AI 偏好 + 提醒规则 + 指南   │
└─────────────────────────────────────────────────────────────┘

扩展模块（P1-P3 优先级）：
├── ⑥ 风险隔离中心     OPC 专属安全盾
├── ⑦ 政策红利地图     主动创收引擎
├── ⑧ 外部协作台       专业服务连接器
├── ⑨ 经营体检报告     月度/季度深度诊断
├── ⑩ 创始人守护中心   个人与家庭风险兜底
├── ⑪ 交易合规工作台   业务发生即合规
├── ⑫ AI 经营教练      主动式决策支持
└── ⑬ 退出规划助手     体面收尾
```

### 1.2 交互规格

#### 核心指标卡片

| 交互 | 行为 |
|------|------|
| 点击卡片 | 跳转对应视图（#/cashflow, #/ledger, #/arap, #/taxburden） |
| 悬停卡片 | 显示详细说明 tooltip（含数据源 _src） |
| 趋势箭头 | 绿色向上（改善）、红色向下（恶化）、灰色（持平） |
| 长按/右键 | 显示「导出该指标数据」选项 |

#### 待办事项中心

| 交互 | 行为 |
|------|------|
| 点击待办项 | 跳转对应视图并高亮相关数据 |
| 勾选待办 | 标记完成，移入「已完成」列表（localStorage 持久化） |
| 悬停待办 | 显示详情和处置建议 |
| 「一键申报」 | 批量跳转纳税日历并筛选待申报项 |
| 「生成催款函」 | 弹窗选择模板 → 生成 PDF → 下载 |
| 拖拽待办 | 调整优先级顺序（可选功能） |

#### 风险雷达

| 交互 | 行为 |
|------|------|
| 点击环形图区域 | 跳转对应风险视图 |
| 点击预警项 | 跳转预警详情 |
| 「查看全部预警」 | 跳转 #/alerts |
| 悬停风险区域 | 显示该域详细风险因子 |

#### OPC 生存仪表盘

| 交互 | 行为 |
|------|------|
| 进度条 | 可视化展示隔离健康度 |
| 倒计时 | 实时显示距年度终了天数 |
| 点击各子项 | 跳转对应视图（#/mixing, #/shareholder, #/annual） |
| 「生成自证报告」 | 导出《财产独立性自证报告》PDF |

#### AI 助手入口

| 交互 | 行为 |
|------|------|
| 点击输入框 | 展开对话界面 |
| 快捷指令 | 预设 prompt，点击即发送 |
| 回车 | 发送问题，AI 响应 |
| 响应结果 | 可跳转对应视图或导出报告 |
| 「生成运营报告」 | 汇总当前数据 → 生成 PDF → 下载 |

### 2.2 交互规格

#### Tab 切换

| 交互 | 行为 |
|------|------|
| 点击 Tab | 切换内容区域，保持页面滚动位置 |
| Tab 标签数字 | 显示待办数量（如「记账中心 (4)」） |
| 快捷键 | Ctrl+1/2/3 切换 Tab |

#### 智能录入

| 交互 | 行为 |
|------|------|
| 拍照识别 | 调用摄像头 → AI 识别发票 → 自动填充表单 |
| 粘贴流水 | 粘贴银行流水文本 → 规则引擎解析 → 生成草稿 |
| 文件上传 | 选择 Excel/CSV → 批量导入 → 预览确认 |

#### 待申报事项

| 交互 | 行为 |
|------|------|
| 「一键申报」 | 跳转电子税局并预填数据（需 API 对接） |
| 悬停税种 | 显示计算明细和法规依据 |

#### 发票队列

| 交互 | 行为 |
|------|------|
| 「一键开票」 | 跳转开票系统并预填信息 |
| 「申请收票」 | 生成申请邮件/短信模板 |
| 点击发票项 | 展开详情（关联合同、流水） |
