### 1.2 问题识别

| # | 问题 | 影响 |
|---|------|------|
| 1 | KPI 8 格过密，移动端体验差 | 信息过载，难以快速定位关键指标 |
| 2 | 缺少「待办事项」汇总区 | 用户需逐个视图查看待办 |
| 3 | 风险预警与合规清单分离 | 风险信息分散，无法一目了然 |
| 4 | 无 AI 助手入口 | 用户无法快速获取智能建议 |
| 5 | OPC 防护卡片过多（9 个） | 重点不突出，P0/P1/P2 混排 |
| 6 | 缺少时间维度对比 | 无法直观看到趋势变化 |

## 三、各区块详细设计

### 3.1 核心指标卡片（4 格）

**布局**：2×2 网格，每张卡片突出一个核心指标

**卡片内容**：

| 卡片 | 主值 | 副值 | 趋势 | 色彩 |
|------|------|------|------|------|
| 现金余额 | 83.59 万 | 招行基本户 09-24 | 较上月 +12.3% | 藏蓝（正常） |
| 本月净利 | 35.67 万 | 收入 47.79 − 支出 12.12 | 较上月 -8.2% | 藏蓝（正常） |
| 应收预警 | 24.12 万 | 6 笔，3 笔逾期 | 1 笔超 90 天 | 红色（预警） |
| 税负健康 | 3.53% | 年初至 9 月累计 | 行业均值 3.2% | 金色（关注） |

**交互**：
- 点击卡片 → 跳转对应视图（#/cashflow, #/ledger, #/arap, #/taxburden）
- 悬停 → 显示详细说明 tooltip
- 趋势箭头：绿色向上（改善）、红色向下（恶化）、灰色（持平）

**响应式**：
- 桌面：2×2 网格
- 平板：1×4 单列
- 手机：2×2 网格（缩小字号）

### 3.2 待办事项中心

**布局**：左右分栏（60:40）

**左侧：待办列表**

```
待办事项中心
├── 紧急待办 (3)  ← 红色标签
│   ├── 🔴 10-15 增值税申报（距今 21 天）
│   ├── 🔴 09-30 办公室租赁续签（距今 6 天）
│   └── 🔴 应收逾期 90 天 - 广州绿洲环保 ¥26,500
├── 本周待办 (5)  ← 金色标签
│   ├── 🟡 09-28 应付到期 - 汇金国际 ¥15,000
│   ├── 🟡 09-30 发票开具 - 湖南智造集团 ¥53,000
│   ├── 🟡 签署股东决定 - 对外担保
│   ├── 🟡 社保基数调整确认
│   └── 🟡 数据分类分级清单建立
└── 已逾期 (2)  ← 灰色标签
    ├── ⚫ 阿里云发票换开（逾期 7 天）
    └── ⚫ 顺丰发票申请（逾期 3 天）
```

**右侧：快捷操作**

```
快捷操作
├── [一键申报] ← 跳转纳税日历
├── [查看合同] ← 跳转合同台账
├── [生成催款函] ← 弹窗生成 PDF
├── [审查合同] ← 跳转合同审查
└── [更多...] ← 展开全部操作
```

**交互**：
- 点击待办项 → 跳转对应视图并高亮相关数据
- 勾选待办 → 标记完成，移入「已完成」列表
- 悬停待办 → 显示详情和处置建议
- 「一键申报」→ 批量跳转纳税日历并筛选待申报项

**响应式**：
- 桌面：左右分栏
- 平板/手机：上下堆叠，快捷操作折叠为图标行

### 3.3 风险雷达

**布局**：上方仪表盘 + 下方预警列表

**仪表盘**：三环形图或雷达图

```
        财务风险 (25/100)
           ╱    ╲
          ╱      ╲
    税务风险    法务风险
    (18/100)   (12/100)
```

**颜色编码**：
- 0-30：绿色（低风险）
- 31-60：金色（中风险）
- 61-100：红色（高风险）

**预警列表**（最近 3 条）：

| 级别 | 域 | 事项 | 状态 |
|------|-----|------|------|
| 🔴 高 | 财务 | 应收逾期 90 天 | 未闭环 |
| 🟡 中 | 税务 | 进项票缺失 | 处理中 |
| 🟡 中 | 法务 | 合同临期 | 待续签 |

**交互**：
- 点击环形图区域 → 跳转对应风险视图
- 点击预警项 → 跳转预警详情
- 「查看全部预警」→ 跳转 #/alerts

### 3.4 经营健康度

**布局**：3 列迷你图表

| 图表 | 类型 | 数据源 | 用途 |

**交互**：
- 点击图表 → 跳转对应视图（#/cashflow, #/ledger, #/budget）
- 悬停数据点 → 显示详细数值 tooltip

**响应式**：
- 桌面：3 列
- 平板：2 列
- 手机：1 列（垂直堆叠）

### 3.6 AI 助手入口

**布局**：底部浮动条

```
┌─────────────────────────────────────────────────────────────┐
│ 🤖 有什么可以帮您？                                         │
│ [输入问题...]                                               │
│ 快捷指令：[分析支出] [审查合同] [查看税负] [生成报告]       │
└─────────────────────────────────────────────────────────────┘
```

**交互**：
- 点击输入框 → 展开对话界面
- 快捷指令 → 预设 prompt，点击即发送
- 回车 → 发送问题，AI 响应
- 响应结果 → 可跳转对应视图或导出报告

**快捷指令**：
- "分析上月支出结构" → 跳转预算视图
- "审查这份合同" → 跳转合同审查
- "查看本月税负" → 跳转税负分析
- "生成运营报告" → 导出 PDF

## 七、验收标准

1. **视觉一致性**：保持投行研究风格（冷灰纸面 + 藏蓝 + 香槟金）
2. **响应式完整**：4 个断点全部适配
3. **交互流畅**：点击跳转、悬停提示、勾选待办均正常
4. **数据准确**：所有数值与 data.js 一致
5. **打印友好**：@media print 样式适配
